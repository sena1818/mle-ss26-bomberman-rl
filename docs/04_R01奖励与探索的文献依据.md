## 1. 先给结论

1. **A03 不是“文献认可的通用死亡罚值”。**它只是本项目在 `{死亡 -5, -1, 0}` 三个点中，第一次同时出现炸箱、部分存活与非零 classic coins 的经验候选；不同地图、状态、`gamma`、动作空间与算法的数值不能照搬。
2. **E01 是合理的下一个单因素实验，不是保证变强的配方。**先高 epsilon 有助于遇到罕见的“放弹—逃生—炸箱”经验，后低 epsilon 减少已学会逃生时的随机致死；但是 epsilon-greedy 只能做逐步随机探索，对长链稀疏任务可能仍然无效。
3. **训练 reward 与 official score 是两件事。**A03 的死亡惩罚改变了训练目标；它并非 policy-invariant reward shaping。是否真的更强，必须由不学习、`epsilon=0`、未改官方环境的独立评测（official score / coins / suicides）决定。
4. 因而下一步应是小而干净的比较：固定 `R01.0 + A03 + C00 + solo classic`，只比较 `E00`（固定 `0.15`）和 `E01`（预先写定的 `0.30 → 0.05` 退火）。**不要同时改 reward、课程、alpha/gamma 或模型。**

## 2. 文献事实：reward shaping 的边界

### 2.1 已有的严格结果

Ng、Harada 与 Russell 证明：在 discounted MDP 中，若希望添加 shaping 后仍保证原 MDP 的最优策略不变，额外项必须采用 potential-based 形式：

```text
F(s, a, s') = gamma · Phi(s') - Phi(s)
```

（另加正线性 reward 变换）。该论文还指出，任意其它变换在某些 MDP 中会改变最优策略。[Ng, Harada & Russell, ICML 1999（原文 PDF）](https://ai.stanford.edu/~ang/papers/shaping-icml99.pdf)

### 2.2 对 R01 的推断（不是该定理本身）

`CRATE_DESTROYED +0.1`、`死亡 -1`、或未来可能的“安全炸弹 +0.3”都不是上式自动保证的 potential-based shaping。因此：

- 它们**可以**作为训练 reward 设计；稀疏任务中这样做很常见。
- 但不能称“不会改变策略”或“只是加速学习”。它们也可能让 agent 偏好刷箱子、回避目标或以错误方式保命。
- 所有 A 版本都须固定保留官方 `COIN_COLLECTED=+1` / `KILLED_OPPONENT=+5` 的外部计分，并报告原始 coins、score、suicides；不能只报训练 return。

这也解释了为什么 A03 的当前证据只能称为“本项目较有希望的训练目标”，不是最终 reward。

### 2.3 “存活”该不该奖励或惩罚？

文献没有给出可跨环境复用的死亡惩罚数值。死亡的效果取决于：死亡是否终止 episode、后续奖励能否获得、折扣、炸弹的短期收益、探索噪声以及 agent 表示能力。

对本项目更准确的操作性原则是：

- A05（死亡 `0`）是必要诊断点：检验“有行为但无风险约束”是否导致快速自杀；
- A02（死亡 `-5`）是另一端诊断点：检验“风险被定得过大”是否使 agent 冻结；
- A03（死亡 `-1`）位于两者之间，必须以独立 greedy 评测确认，不应由近似期望值公式单独宣布最优。

这是**本项目的剂量—响应推断**，不是把某篇论文的数值复制过来。

## 3. 文献事实：epsilon 退火能说明什么、不能说明什么

### 3.1 它是常见基线做法，不是普适最优值

早期 DQN 工作在训练期使用 epsilon-greedy，并把 epsilon 从 `1.0` 线性退火到 `0.1`，之后保持；同时把评测建立在跨多局的平均回报上。作者也明确将 hyperparameter 选择视为经验性的、面向具体任务的选择。[Mnih et al., *Playing Atari with Deep Reinforcement Learning*（作者公开 PDF）](https://www.cs.toronto.edu/~vmnih/docs/dqn.pdf)

**可引用的事实：**“先多探索、再少探索”的时间表是成熟 value-based RL 基线中实际使用过的设计。

**不可推出的结论：**这不证明 R01 应使用 `0.30 → 0.05`，更不证明 500 局内一定优于固定 `0.15`。DQN 的网络、replay、target network、游戏与训练量都不同于 R01。

### 3.2 稀疏、需要连续正确动作时，epsilon-greedy 有结构性局限

Dann 等人在带函数逼近的 episodic RL 中分析 epsilon-greedy：这种“myopic”探索在一些问题可有效，但其样本复杂度取决于任务动力学、reward 与 value class 的结构；并非任何稀疏任务都能靠调一个 epsilon 解决。[Dann et al., ICML 2022](https://proceedings.mlr.press/v162/dann22a.html)

更强的反例研究指出，epsilon-greedy 这样的逐步随机扰动不产生一段一致的探索策略；在需要长序列探索的 MDP 中，学习时间可急剧恶化。[Osband et al., *Deep Exploration via Bootstrapped DQN*](https://arxiv.org/abs/1602.04621)

**对 R01 的推断：**Bomberman 的“放弹后连续走到安全处”正有短而关键的序列结构。E01 值得测，但若 E01 仍不能让多数 seed 形成安全炸箱，正确结论应是“本线性 online Q-learning + epsilon-greedy 的探索不足”，而不是无止境延长轮数或继续调 reward。

### 3.3 与 Bomberman 最接近的直接证据

Kormelink、Drugan 与 Wiering 在 Bomberman 上比较了 greedy、random walk、epsilon-greedy、diminishing epsilon-greedy、Max-Boltzmann 等 Q-learning 探索方式；研究结论支持“探索—利用组合应被显式比较”，而不是纯贪心或纯随机。其设置中 Max-Boltzmann 表现最好，部分 epsilon 变体则不稳定。[Kormelink, Drugan & Wiering, ICAART 2018（作者 PDF）](https://www.ai.rug.nl/~mwiering/GROUP/ARTICLES/ICAART_EXPLORATION_BOMBERMAN_2018.pdf)

该证据的适用边界很重要：它使用的是 7×7、多智能体、不同 reward/动作/网络/预算的 Bomberman。它支持 E 维度值得单独实验，**不支持**我们直接改用它的 epsilon 或宣布 Boltzmann 一定更好。

## 4. 文献事实：为什么必须把训练和评测分开

Machado 等人总结 Atari 评测协议时发现：环境随机性、模式和评估做法的差异会使结果难以比较，因而需要预先定义的评测协议。[Machado et al., JAIR 2018](https://arxiv.org/abs/1709.06009)

Henderson 等人进一步展示，即使超参数不变，随机 seed 也可导致显著不同的 RL 曲线；只挑一个最好 seed 或只报单点平均会误导结论。[Henderson et al., AAAI 2018](https://ojs.aaai.org/index.php/AAAI/article/view/11694)

因此 R01 应坚持：

- 训练期可使用 epsilon；评测一律 greedy（`epsilon=0`）、不更新模型；
- validation checkpoint 选择与 holdout 汇报 seed 分开；
- 同时报均值、标准差、每个 training seed 以及 checkpoint 曲线；
- 行为诊断（bombs、crates、suicides、wait fraction）解释机制，official score / coins 决定是否真的更强；
- 不因单个高分 seed 晋升 checkpoint 或改写结论。

## 5. 对下一步 A03 × E01 的预注册建议

以下是基于上面文献与已完成 A02/A03/A05 观察的**项目建议**，不是外部论文的结论。

### 问题

在 A03 下，把训练探索从固定 `epsilon=0.15` 改为预先指定的 E01 退火，能否让更多随机 seed 在 solo classic 中学到“安全炸箱并采币”，且不提高 greedy 自杀？

### 固定不动的内容

```text
R01.0     handcrafted_v1 (44d) + linear multi-head Q + online Q-learning
A03       当前死亡 -1 reward 版本
C00/T03   无课程、solo classic
mask      训练探索、greedy 与 TD target 均保持合法动作 mask
alpha/gamma、训练 rounds、checkpoint 频率、train/eval seed 协议
```

唯一改变：

```text
E00: epsilon 恒定 0.15
E01: epsilon 依预注册公式由 0.30 退火至 0.05
```

### 如何读表

1. **能力主指标（holdout greedy）**：official score、coins、suicides；以每个训练 seed 的 round-500 checkpoint 和总体均值/方差一起看。
2. **机制指标（同一 holdout greedy）**：bomb rate、crates per round、approximate safe-bomb rate、wait fraction。它们回答“变强/变弱是因为更敢炸、会逃、还是只是在等”。
3. **学习过程**：每个 checkpoint 的 validation 和 holdout 曲线。不要用 score=0 的早期 checkpoint 自动覆盖“已有炸箱行为”的 checkpoint，也不要从曲线最高点倒推挑新超参。
4. **判读规则**：只有当 E01 在多数 training seed 的 greedy holdout 上提高或至少不降低 coins/score，并且不恶化 suicides，才可以称它对 A03 有益。若只是训练期 bomb rate 增加，不能称能力提升。

### 决策

| E01 结果 | 合理的下一步 |
|---|---|
| 多数 seed 有更稳定的炸箱、非零 coins，且 greedy suicides 不升 | 固定 E01，才做 A03 的更长训练预算消融（例如 1,500–2,000 rounds）。 |
| 多数 seed 仍然冻结 | 不直接加轮数；先承认 epsilon-greedy 或价值学习的探索瓶颈，设计新的 R 或 E 路线。 |
| bombs / crates 上升但 greedy suicides 也上升、coins 不升 | E01 的前期随机性过强或 A03 仍不平衡；不要把它称为成功。 |
| seed 间结论矛盾 | 扩充独立 seed、保留完整曲线；不从少数赢家 seed 作结论。 |

## 6. 后续方法的边界

Pommerman 的公开研究也将该问题描述为稀疏、延迟奖励的训练难点，并结合 imitation、reward shaping、action filter 与 curriculum 来加速训练。[Meisheri et al., 2019](https://arxiv.org/abs/1911.04947)

这不是“立刻把所有技巧加进 R01”的理由，恰好相反：

- 如果引入 curriculum、imitation、action filter、replay 或新的 state feature，应当建立新 R/C 版本；
- 如果加辅助 reward，优先设计可审计的 potential-based 形式；若不满足，就显式标注为“改变训练目标的经验 shaping”，并用 classic official metric 及反刷分诊断评估；
- A03 × E01 的唯一目的是测 exploration schedule，不能夹带这些改动。
